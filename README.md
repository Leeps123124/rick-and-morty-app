# Rick and Morty App

Учебное SPA-приложение для просмотра персонажей вселенной «Рик и Морти».
Данные загружаются из публичного [Rick and Morty API](https://rickandmortyapi.com/).

## Реализовано

- вывод списка персонажей из API;
- поиск персонажей по имени с debounce-задержкой;
- серверная пагинация;
- отдельная страница с подробной информацией о персонаже;
- добавление и удаление персонажей из избранного;
- сохранение избранного в `localStorage`;
- состояния загрузки и ошибки;
- отдельная страница для неизвестного маршрута;
- адаптивная вёрстка.

## Стек

- React 18;
- TypeScript в строгом режиме;
- Vite;
- React Router 6;
- TanStack Query;
- Axios;
- Redux Toolkit;
- CSS Modules;
- Oxlint.

## Архитектура

Проект использует FSD-подобное разделение на слои:

- `app` — запуск приложения, провайдеры, роутинг и Redux store;
- `pages` — страницы приложения;
- `widgets` — составные блоки интерфейса;
- `features` — пользовательские действия: поиск, пагинация и избранное;
- `entities` — модель и API персонажа;
- `shared` — общий API-клиент, хуки и UI-состояния.

Серверные данные хранятся в кэше TanStack Query. Клиентское состояние избранного хранится в Redux Toolkit и синхронизируется с `localStorage`.

## Маршруты

- `/characters` — список персонажей;
- `/characters/:id` — информация об отдельном персонаже;
- `/favorites` — избранные персонажи;
- `/` — перенаправление на список персонажей;
- неизвестный адрес — страница 404.

## Запуск проекта

```bash
npm install
npm run dev
```

Сборка и проверка кода:

```bash
npm run build
npm run lint
```

## Проверка

Проверены поиск, пагинация, переход на страницу персонажа, добавление и удаление избранного, сохранение избранного после перезагрузки и обработка неизвестных маршрутов. Команды `npm run build` и `npm run lint` выполняются успешно.

Автоматические тесты пока не добавлены.
